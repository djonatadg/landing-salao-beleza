# Belle Studio — Landing Page

Projeto demonstrativo de uma landing page para salão de beleza, desenvolvido com HTML, CSS e JavaScript.

A proposta do projeto foi criar uma página moderna, elegante, responsiva e com foco em conversão por meio de contato direto pelo WhatsApp.

## Demonstração online

Acesse o projeto publicado:

**https://landing-salao-beleza.vercel.app**

> Substitua o endereço acima pelo link real do projeto publicado na Vercel.

## Funcionalidades

- Layout responsivo
- Hero section com chamada principal
- Seção de serviços
- Galeria em carrossel
- Lightbox para ampliar imagens
- Navegação por teclado na galeria
- Botões de contato via WhatsApp
- Header fixo com efeito durante a rolagem
- Animações suaves ao entrar na tela
- Layout adaptado para desktop e dispositivos móveis

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Git
- GitHub
- Vercel
